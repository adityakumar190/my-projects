Project 2: Mapping Using QGIS

Description: Meteor impacts are among the most significant geological events in Earth's history, leaving behind large-scale surface features known as impact craters. This project presents an interactive Geographic Information System (GIS) atlas that visualizes the global distribution of selected ancient meteor impact craters. The project uses GIS techniques to map the geographic locations of 20 major meteor impact structures around the world. Each crater location is represented as a spatial point feature, with crater diameter used to represent the relative size of the impact structure through proportional symbols. The map also includes interactive information panels containing important details such as crater name, country, and reference sources. The project was developed using QGIS, an open-source GIS software platform, and further converted into a web-based interactive map to improve accessibility and exploration. Users can interact with the map by selecting individual crater locations to view associated information. The aim of this project is to demonstrate how GIS can be used for geological visualization, spatial analysis, and communication of Earth's geological history through an interactive mapping approach.

Project 3: Sentiment Analysis

Description: In this project, sentiment analysis is applied to YouTube comments related to two space mission narratives: the story of Laika, the first dog sent into space, and Vladimir Komarov, a Soviet cosmonaut who died during a space mission. The study uses two different approaches for sentiment classification: a rule-based method (TextBlob) and a transformer-based model (Twitter-RoBERTa). The objective is to analyze and compare audience reactions across both datasets and methods to understand emotional responses toward human and animal space mission tragedies.
